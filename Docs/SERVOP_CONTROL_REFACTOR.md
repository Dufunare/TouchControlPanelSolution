# ServoP 实时控制结构重构（2026-11-06）

> 状态：PR #3 Draft；源码及 C++17 离线用例通过；**Windows Qt 完整构建、机械臂实际速度、加速度、制动距离及碰撞安全性尚未验证**。本改动不是安全认证，也不是解除硬停止门槛。

## 用户反馈与已知瓶颈

原始 `master` 的 ServoP 在控制上比 PR #3 灵敏，而后来的 2×、4× 比例和 12/16/20mm 预瞄调节仅有限改善。早期日志实际TCP路径速度 ~54–57mm/s、已发送目标路径速度 ~61–64mm/s，反馈前视限制触发几乎每一帧；Y 贴近 -350mm 时又产生大量 WORKSPACE HOLD。此外存在 8891 反馈超过250/400ms的停发或 ResetRobot。不能将上述问题全部归咎于网络。

## 设计边界

以 **最新 Touch 相对位置** 作为独立意图，由 `RelativeServoP` 的离合状态机负责捕获 Touch 与8891实际TCP抓取基准。位置映射保持 X←Touch X, Y←−Touch Z, Z←Touch Y（均可在启动前换轴/反向）。每次 Button1 松开停止生成目标；需要三帧不同 `state_seq` 的空闲反馈以及一次新按下才重新抓取。旧的绝对Touch位置不会影响新基准。

`shared/ServoPCommandPlanner.h` 为纯 C++17 的**实时目标仲裁器（不是认证的速度/加速度轨迹规划器）**：

1. 输入：本周期最新Touch映射目标 `latestTouchGoal`、上次本地TCP成功写入目标 `lastSent`、当前有效的8891实际反馈 `actualTcp`；没有待处理目标FIFO。
2. 先逐轴处理软件XYZ实验边界（越界轴保持上一条安全目标），其他轴仍可移动；离合球形范围在该步骤后计算，避免超大越界Y分量抢占有效X/Z方向。
3. 将最新意图相对 `lastSent` 的一次目标位置跳变约束在20mm内；若候选目标相对当前 `actualTcp` 超过20mm，则**只沿当前意图与已发目标的线段裁取可容许部分**，而不直接重建成 `actualTcp + 20mm`。反馈没有成为期望位置的原点。
4. 当前位置尚未跟上上一目标时，新远距离指令会进入 `TrackingHold`，不会积压并随后重放；下一次刷新时使用**最新**Touch值。
5. 对全部候选仍进行最终数值/工作空间验证；`acknowledgeSentTarget` 只在本地8888 TCP发送成功后更新 `lastSent`，这**不代表机器人端已经接收、接受或执行指令**。
6. 仅用于实验的软件限制包括：候选超前实际TCP最多20mm、相邻发送目标位置变化最多20mm；已发送目标相对真实8891 TCP超过25mm、机器人状态异常/反馈无效会停止。不可将这些数值当作经过设备厂商确认的速度、加速度、机械停止距离、可达路径或避障约束。

`DeviceController::runServoPTick` 对直接控制模式只使用上述规划仲裁结果和独立的**已发送目标/实际TCP**硬跟踪监视，不再把旧 `ServoPFlowGuard` 的16mm软保持和11mm恢复滞回**重复叠加**在新的仲裁结果上。旧控制路径代码仍保留作实验兼容，但不会由当前Qt ServoP入口选用。反馈短暂丢失会立即停发并撤销本次离合；持续超时和明确失联保留原软件停止路径。

## 与原始 master 的区别（不要夸大改善）

| 行为 | 原始 master | PR#3旧路径 | 本轮重构的直接路径 |
|---|---|---|---|
| Touch目标 | 相对位置映射 | 相对位置映射 | 相对位置映射 |
| 向实际TCP重新定义目标 | 否 | 是（实际TCP+12/16/20mm） | **否**，反馈只用于仲裁 |
| 独立逐帧60/120mm/s推进器 | 否 | 是 | **否** |
| 目标变化受限 | 仅0.3mm死区 | 逐帧步幅、前视、软件工作空间 | **20mm目标跳变**、20mm反馈安全包络、软件工作空间 |
| 旋转姿态 | 硬编码 | 当前真实抓取姿态锁定 | 当前真实抓取姿态锁定 |
| 反馈失联终止 | 较弱 | 有 | 保留 |
| 离合重新抓取 | 较弱 | 有 | 保留 |

本次重构消除了重复软HOLD和将实际反馈当作追赶参考的算法路径，但**20mm反馈安全包络仍可能限制持续速度**。只有在了解CR3控制器真实运行速度、加减速、制动距离、固件ServoP插值和安全区域后，才能论证是否有资格调整这一约束。绝不能凭“不够快”直接放大它，或认为到达目标后即刻停止。

## 验证和上线限制

- `tests/servop_command_planner_tests.cpp` 只检查纯算法：突变指令/小包裹、安全包络边界、实际反馈前进、Touch反向、Y界外的X切向输入、错误数值、释放与新的基准抓取。
- GitHub Actions C++17 offline job 已通过；**不等于 Qt Windows 编译通过，更不等于实体运动测试/功能安全验收**。
- 本轮不调整中转站 `master`、控制器固件参数或 ServoJ/MovL 指令。不声称已经解决8891独立超时或中转站内部积压。
- 正式实机使用之前需由现场人员完成制造商指定工作空间、机械速度和加速度、限位、保护停止、实物急停、离合释放后末端残余运动等安全评审。禁止在人员进入机械臂危险区时通过该实验模式运动。
