**结论：**V3 原生 ServoP 支持六维位置目标，不能将仅在 ServoJ 文档中列出的 t/lookahead_time/gain 移植给本版本的 ServoP。维持现有 33ms 控制周期、原六参数发送链路和所有既有平移、离合、停止门禁。不自动改变 User/Tool、速度、加速度、碰撞检测、负载或关节限位。文档没有明确说明 Rx/Ry/Rz 的组合次序及 ActualQuaternion 的参考坐标系，且名义关节活动范围不能证明当前安装的碰撞安全。

## 已接入真实控制器的只读证据

1. relay_station 现有 relay_core.cpp 已从 1384 读取 actualQuaternion，并在 8891 robot_state 发布 actual_quaternion。不需修改中转站。上位机仅接受有限、近单位长度的四元数；每帧独立解析，缺失或非法时绝不继承旧姿态，原平移路径保持兼容。
2. 高级设置“采集当前姿态证据（只读）”在空闲、静止、新鲜且 User=0/Tool=0 的反馈下对照六种旋转矩阵乘法顺序。至少三个实际角距离彼此不小于 5° 的姿态、最佳候选最大残差不大于 0.5°、次优候选最大残差不小于 2°才报告唯一候选。阈值仅用于证据筛选，并非物理限位。四元数正负等价；单轴姿态可能无法区分旋转次序。按会话保存证据，反馈失效即清除，允许手工清除。不得由本工具自动移动机器人采样。
3. 固定轴六维预览保持原位置/姿态的共同离合锚点。预览记录 session/User/Tool，变化后不再使用旧锚点。保持旋转矩阵乘法、最近欧拉角等价分支选择和奇异姿态拒绝。
4. “验证六维预览目标逆解（只读）”仅在已停止实体模式、本会话支持 ZYX、当前默认坐标系/稳定反馈/有效离合和目标有效时，向现有 8891 发出唯一请求 ID 的 29999 InverseSolution 计算。以同帧实际关节为 JointNear，要求完整回显的六维目标、User/Tool、近解标志与六关节参考吻合。检查会话、状态、时效、六关节有限性；记录目标、解、最大关节差、RTT 和 CR3 手册名义关节范围的对照。它不向 30003 发指令，不将逆解结果交给 ServoJ 或任何真实运动发送器。一次探测仅验证终点逆解，不证明整条路径可达、远离奇异或无碰撞。
5. 诊断在途不允许开始实体模式。由于 relay 的 Dashboard 回包账本按 FIFO 匹配，超时/断线/回显错配后可能存在未处理请求，故本进程锁定新实体模式（普通已确认的控制器逆解拒绝不视为不确定）。现场人员应确认机器人停止，按批准流程恢复中转站及上位机连接后再运行。停止/急停路径不因诊断而禁用。

## 现场验收与剩余边界

- 记录控制柜实际固件版本、DobotStudio Pro 的 User/Tool、负载/偏心、已批准的关节及工作空间限制、碰撞和独立物理急停等现场配置。文档版本不能代替实际设备配置。
- 由现场合格人员在风险评估允许的姿态和既有官方控制/示教流程下采集多个静止姿态。保持同一有效 8891 会话；若断线不拼接证据。不需要为了校验而执行本程序发出的动作。保存 [ROTATION AUDIT] 完整日志。若不是唯一 ZYX，则先纠正帧/顺序假设。
- 以固定轴六维只读预览检查各旋转方向、离合重抓，以及平移和旋转组合。记录 [ROTATION IK / READ ONLY] 的返回或拒绝。
- 新增独立的 ServoP 固定 TCP 实体旋转小角试验模式（默认仍为平移）。操作者必须先确认本机固件/ZYX 姿态证据、控制器限位与安全配置、局部路径及奇异/碰撞风险，现场人员批准后才能进入待命。不可把 ±360°、180°/s 等名义规格当作遥控许可。尚未完成真机验收；不开放平移+旋转混合或大角度跟随。

## 实体旋转小角试验

- 在当前 8891 会话获取唯一 ZYX 实测证据后，选择“ServoP · 固定TCP实体旋转（小角试验）”，确认本次现场安全前提，松开 Button1，启动。需要实际四元数、User/Tool=0、有效 Touch 姿态、空闲及新鲜反馈。禁止自动获取证据而移动机械臂。按下只捕获基准，下一帧才可能发送运动。
- 固定当前离合的 XYZ，触控笔矩阵相对旋转按原固定轴映射变换，角度不使用平移倍数；只发送六参数 ServoP。限制三位小数的最终 RPY 步长之和 ≤0.20°、目标姿态相对离合和本次启动均 ≤2°、相对反馈四元数的角距离 ≤1°。不排队、不补偿被限幅的输入；静止不追赶。重新离合不能扩大本次启动的总姿态试验范围。
- 每帧使用当前实测四元数及关节状态；新鲜度上限 150ms、relay heartbeat 上限350ms；实际旋转相对启动 ≤3°、实际与最近发送角误差 ≤1.5°、TCP 相对启动偏移 ≤2mm、实际/目标关节相对启动实测关节 ≤3°、实测关节速度 ≤5°/s、控制节拍异常停发；跟踪误差超过0.5°持续1.5秒终止模式。保留原反馈、工作空间、会话、Touch 校准及停止联锁。四元数/关节/控制状态失效立即结束模式，不退化为平移。未发送目标不推进参考。
- 上述数字是新增的保守软件试验包络，不是由厂商认证的安全速度或碰撞范围；关节目标和实际反馈检查只能发现部分问题，不能预判奇异、关节路径、制动距离或所有碰撞。控制器已有保护和现场独立急停不可停用。须由现场合格人员依实际控制器配置确认允许的局部试验区域，必要时先做只读逆解探测。没有现场确认不得启动。
- 日志：[ROTATION ARMED]、[ROTATION START BLOCKED]、[ROTATION FOLLOW]、[ROTATION STOP]；原 SERVOP RELEASE STOP/STOP ACK/READY 同样适用。
